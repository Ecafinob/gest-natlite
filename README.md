#gest-natlite

L'application devra permettre de :
•	enregistrer une naissance ;
•	gérer les informations relatives aux parents ;
•	consulter, modifier et supprimer les dossiers de naissance selon les droits de l'utilisateur ;
•	rechercher rapidement un dossier ;
•	produire des statistiques sur les naissances ;
•	sécuriser l'accès aux données grâce à une authentification.
